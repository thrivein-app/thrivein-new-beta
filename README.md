# Kretopia 

🚀 ThriveIN MVP – Core Features

1. Onboarding + Credits

Sign up via Google, Instagram, or email.

Guided onboarding with credits/coins reward for each step:

Upload profile pic → +10 credits

Add bio/skills → +10 credits

Connect socials (Spotify, YouTube, Instagram) → +20 credits

Invite 3 friends → +50 credits


Credits usable for swipes, boosts, EPK views, or proposals.



---

2. Profile / EPK (Minimum Viable Version)

Upload photo, name, role (musician, designer, filmmaker, etc.)

Tabs: About | Portfolio | Reviews (Spotify/YouTube placeholders)

Shareable profile link (mini EPK page).

Reviews/endorsements system (basic star rating).

AI suggestion tool: auto-generate bio, tagline, or skill highlights.



---

3. Discover (Jobs, Barters, Collabs)

Swipe-style discovery:

Creators (for collabs & networking)

Opportunities (jobs, barters, gigs)


Brands/Venues Fast Post:

Skip full signup → click “Create Opportunity” → fill quick form → publish instantly (drives network growth).


Filters: Location, industry, paid/barter/free.



---

4. Dashboard

Overview of:

Balance (credits + ThrivePay balance).

Proposals sent/received.

Projects active.


Activity log (e.g., “Proposal sent,” “Offer received”).

Quick actions: Add Spark, Send Proposal, Withdraw Earnings.



---

5. ThrivePay

Wallet to manage coins/credits + real payments.

Users can:

Earn from gigs.

Withdraw to bank/PayPal (placeholder).

Buy credits with real money (in-app purchase).


Referral rewards → extra credits for each signup.



---

6. Sparks (Social Feed)

Post updates, audio, images, videos.

Like/react (🔥 etc.) with coins-based boosting.

“For You” feed = AI-matched suggestions (creators, jobs, collabs).



---

7. ThriveStudio

AI-first creative tools hub:

Copy (generate bios, captions, pitches).

Images (basic prompt-to-image).

Music/Voice/Video placeholders (coming soon).


Export/share to Sparks or Profile.

Credits required for premium generations.



---

8. ThriveDesk

Basic project & task board (MVP).

Create workspace → add files, tasks, simple chat.

Placeholder for advanced collab tools later.



---

🎯 Monetization + Gamification

Free Tier: limited swipes/discover per day, basic portfolio.

Pro Subscription ($9.99–$19.99/month): unlimited swipes, boosted discoverability, extra storage, AI boosts.

Coin System:

Earn by onboarding, inviting, posting, completing gigs.

Spend on boosts, AI studio, extra swipes, or unlocking premium gigs.


Referral Flywheel: Share profile → invite friends → earn coins.



---

⚡ Competitive Advantage (AI + Matching)

AI auto-matching for:

Jobs ↔ creators.

Creators ↔ collaborators.

Brands ↔ talent.


Profile insights → “People like you also connected with…”

AI portfolio builder (auto-design EPK templates).
